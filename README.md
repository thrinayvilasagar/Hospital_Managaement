# Hospital Management System

## Project Description
Hospital Management System is a desktop-based application developed using Java and MySQL. The project helps manage hospital operations efficiently, including patient records, doctor information, appointments, and other administrative activities.

The main purpose of this system is to reduce manual work, improve data management, and provide quick access to hospital-related information.

## Features

- Patient Registration
- Doctor Management
- Appointment Scheduling
- Patient Records Management
- Search Functionality
- Update/Delete Records
- Database Connectivity with MySQL
- User Login System
- Simple and User-Friendly Interface

## Technologies Used

- Java
- MySQL
- JDBC (Java Database Connectivity)
- Swing / AWT (if used for GUI)
- NetBeans / Eclipse / IntelliJ IDEA

## System Requirements

### Software Requirements
- Java JDK 8 or above
- MySQL Server
- IDE (NetBeans/Eclipse/IntelliJ)
- MySQL Connector JAR

### Hardware Requirements
- Processor: Intel i3 or above
- RAM: 4 GB minimum
- Hard Disk: 500 MB free space
